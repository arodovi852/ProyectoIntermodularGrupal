# Guía para Contribuir

¡Gracias por tu interés en contribuir a este proyecto! A continuación, se detallan las pautas para contribuir de manera efectiva.

## Cómo empezar

1. **Clona el repositorio**: Asegúrate de tener una copia local del proyecto.
   ```bash
   git clone <URL_DEL_REPOSITORIO>
   ```

2. **Crea una rama**: Trabaja en una rama separada para tus cambios.
   ```bash
   git checkout -b nombre-de-tu-rama
   ```

3. **Instala las dependencias**: Asegúrate de instalar todas las dependencias necesarias.
   ```bash
   npm install
   ```

## Reportar problemas

Si encuentras un error o tienes una sugerencia, abre un nuevo "issue" en el repositorio. Proporciona la mayor cantidad de detalles posible, incluyendo:
- Pasos para reproducir el problema.
- Comportamiento esperado.
- Comportamiento actual.

## Hacer cambios

1. **Sigue las convenciones de codificación**: Asegúrate de que tu código sigue las normas establecidas en el proyecto.
2. **Escribe pruebas**: Si agregas una nueva funcionalidad, incluye pruebas para garantizar su correcto funcionamiento.
3. **Documenta tus cambios**: Actualiza la documentación si es necesario.

## Enviar un Pull Request

1. **Asegúrate de que tu rama esté actualizada**: Sincroniza tu rama con la rama principal.
   ```bash
   git pull origin main
   ```

2. **Realiza un commit de tus cambios**: Asegúrate de escribir mensajes de commit claros y descriptivos.
   ```bash
   git commit -m "Descripción de los cambios"
   ```

3. **Envía tu rama al repositorio remoto**:
   ```bash
   git push origin nombre-de-tu-rama
   ```

4. **Abre un Pull Request**: Ve al repositorio en GitHub y abre un nuevo Pull Request. Proporciona una descripción detallada de los cambios realizados.

## Código de Conducta

Este proyecto sigue un Código de Conducta. Al participar, aceptas cumplir con sus términos.

## Contacto

Si tienes alguna pregunta, no dudes en ponerte en contacto con los mantenedores del proyecto.
