# Changelog

Todas las notas importantes sobre los cambios en este proyecto se documentarán en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es/1.0.0/), y este proyecto sigue [Versionado Semántico](https://semver.org/lang/es/).

## [1.0.0] - 2026-02-02
### Añadido
- Creación inicial del proyecto con estructura básica para frontend y backend.
- Configuración de Docker para desarrollo y producción.
- Implementación de autenticación JWT en el backend.
- Documentación inicial en `README.md`, `CONTRIBUTING.md` y `CODE_OF_CONDUCT.md`.
- Configuración de ESLint para el frontend.
- Configuración de rutas y controladores básicos en el backend.
- Implementación de vistas y componentes iniciales en el frontend.

### Cambiado
- Ajustes menores en la estructura de carpetas para mejorar la organización.

### Eliminado
- Archivos y configuraciones innecesarias del proyecto inicial.
